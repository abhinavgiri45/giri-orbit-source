# Security Policy — Giri Orbit (Native C++ Source Edition)

## Supported Versions

The latest released version is actively maintained with security enhancements:

| Version | Supported          |
| ------- | ------------------ |
| 15.x.x  | :white_check_mark: |
| < 15.0  | :x:                |

## Reporting a Vulnerability

If you discover any potential security vulnerability, security loophole, or data leak within Giri Orbit, please **do not open a public issue**.

Direct all reports privately to:
- **Author**: Abhinav Giri
- **Email**: `abhinavgiri370@gmail.com`
- **Subject**: `[SECURITY VULNERABILITY] Giri Orbit Report`

Please include:
1. Detailed description of the potential vulnerability
2. Reproducible steps or proof-of-concept
3. Affected components (Drift, Axis, Kinetic, Forms, etc.)

All valid security reports will be acknowledged and remediated promptly by Abhinav Giri.
